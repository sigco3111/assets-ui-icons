# Long Wind 수묵 세리프 폰트 4종 (Google Fonts, OFL)

수묵 무협 게임 Long Wind의 타이틀·본문에 쓰인 Google Fonts 4종입니다. 한글 명조(Noto Serif KR), 중국어 간체 세리프(Noto Serif SC), 중국어 서예 필기체(Ma Shan Zheng), 라틴 세리프(Cormorant Garamond, 가변+이탤릭)로, 수묵·무협·동양풍 게임 UI에 맞는 조합입니다.

**라이선스: SIL Open Font License 1.1.** 각 폴더의 OFL.txt 전문을 유지하면 사용·재배포할 수 있습니다. 폰트 단독 판매는 금지되고 수정본은 동일 라이선스여야 합니다.

## 내용 (zip, 4폴더 9파일)

- `ma-shan-zheng/` — MaShanZheng-Regular.ttf
- `noto-serif-kr/` — NotoSerifKR[wght].ttf (가변)
- `noto-serif-sc/` — NotoSerifSC[wght].ttf (가변)
- `cormorant-garamond/` — CormorantGaramond[wght].ttf + Italic
- 각 폴더 OFL.txt 전문 동봉

## 확인 사항

- google/fonts 공식 저장소(ofl/<family>) 파일 그대로이며, 2026-11-24 API 목록의 바이트 크기와 일치함을 확인했습니다.
- 출처: https://fonts.google.com · 사용 게임: https://github.com/jbang2004/long-wind (Google Fonts CDN 로딩)
- 수집일: 2026-11-24 · 파일: Releases(long-wind-fonts)에 분할 압축으로 첨부. 25MB 업로드 제한으로 zip 29MB를 나눴습니다. long-wind-fonts.z01과 .zip 2개를 모두 내려받아 같은 폴더에서 `zip -s 0 long-wind-fonts.zip --out full.zip`을 실행한 뒤 full.zip을 풀면 됩니다.
